# PEOPLE, PLACES & ME — Teacher Guide

**Age:** 11–12  
**Level:** A1+ → A2  
**Mode:** one student + one tutor  
**Course:** Spotlight 6, Module 1 companion course — integrated-skills revision

## Method

The course keeps vocabulary slightly heavier because lexical recall is a known pressure point, but the Core Route is now integrated-skills:

**context → receptive input → notice → understand → practise → retrieve → personalise → communicate**

Reading and listening use **prediction → gist → detail → evidence / noticing → response**. Writing and speaking are supported by useful language, a first attempt, optional scaffolding and tutor feedback.

There is no Cambridge rule requiring equal percentages for every skill. For this course, a sensible design target is approximately:

- vocabulary / lexical retrieval: 25–30%
- grammar / form-focused work: 15–20%
- reading: 12–15%
- listening / video: 12–15%
- speaking: 15–20%
- writing / mediation: 10–15%

These are design targets, not compulsory lesson-time quotas. If vocabulary needs more recycling, use Word Lab as Extra Practice rather than replacing receptive or productive work.

## Updated route

1. **Family Files** — family + have got + original reading + built-in listening + speaking; optional short family video.
2. **Face Detective** — appearance + listening identification + short reading + speaking.
3. **Whose Is It?** — possessives + lost-property reading + short functional writing + speaking.
4. **Identity Check** — personal information + registration listening + safe identity writing + role-play.
5. **Passport Quest** — countries/nationalities + travel reading + optional Europe video + speaking.
6. **Where in the World?** — directions + map listening + reading-to-build-a-mental-map + communication.
7. **Country Lab** — UK / country facts + optional short UK video + 60–80 word country factfile.
8. **The World File** — integrated final listening + 80–100 word profile + final speaking.

## Listening routine

Built-in listening uses browser speech synthesis, so the Core Route does not depend on an external service.

1. Read the task and options only.
2. Listen once for gist.
3. Listen again for detail.
4. Check answers.
5. Open the transcript only after the first check.
6. Use the transcript for noticing and correction.

If speech synthesis is unavailable, the tutor can read the matching script naturally from LISTENING-SCRIPTS.md.

## Video routine

YouTube clips are **optional authentic input**. They do not carry Core Route progress and may be skipped if YouTube is blocked.

Suggested sequence: **predict → watch/listen → collect target language → report → personalise**.

See VIDEO-SOURCES.md for the exact videos and selected sections.

## Writing routine

Writing is not auto-marked as correct/incorrect.

Use: learner first draft → checklist → optional frame → model only after a draft → tutor gives one success and one improvement target → learner improves one or two sentences.

Drafts save locally. **NEW STUDENT** clears the main course progress and the additional writing storage.

## 1:1 interaction

Keep using Tutor Follow-up and short speaking bridges. Do not interrupt the first speaking attempt. Note one successful feature and one target improvement, then repeat if useful.

## Correction priority

- meaning first
- have got form and word order
- possessive adjective vs possessive pronoun
- country vs nationality
- be vs have got in appearance
- capitalisation of proper nouns
- full-sentence answers
- comprehensibility before minor accuracy in first-draft writing

## Core Route vs Extra Practice

**Core Route:** mission stages + integrated reading/listening/writing/speaking.  
**Extra Practice:** Word Lab and optional YouTube panels.

Do not let Word Lab consume the whole lesson. If vocabulary is weak, add one short retrieval round and then return to the mission so the learner uses the language receptively and productively.

## Reset

The integrated-skills revision uses a fresh local progress version so older saved answers do not attach to newly inserted stages. **NEW STUDENT** clears the active course data and additional writing drafts.


## Side Quest Garage — teen game layer

**Purpose:** add choice, novelty and teenage-friendly contexts without turning the course into a racing game or replacing the language progression.

The automotive / tech theme is a motivational wrapper: model cars, motor-show displays, family bike trips, maps, cameras and transport technology. The course does **not** place 11–13-year-olds in adult driving situations.

The seven optional quests are non-linear:

- **Whose Gear?** — possessive adjectives, possessive pronouns and possessive ’s in a lost-property context.
- **Map Run** — compass directions, route decoding and oral retelling.
- **Crew Scan** — reading for specific information and textual evidence.
- **Garage Radio** — listening for gist and detail; transcript unlocks after an attempt.
- **Quick Shift** — sentence building and word order.
- **Build a Ride** — meaningful choice → short writing → 30–45 second speaking pitch.
- **Road Trip Boss** — final integrated speaking task with identity, family, possessions and location language.

Quest keys are motivational progress only. There are no lives, penalties or mandatory speed. The optional 45-second timer in the Boss task supports fluency practice; it never determines success.

### Suggested use in a 60-minute lesson

A strong route is:

**Core input → one controlled Core task → one Side Quest chosen for the learner’s current need → productive Core task → reflection.**

Do not try to complete all seven quests in one lesson. They are a reusable practice layer across the whole unit.

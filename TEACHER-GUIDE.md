# PEOPLE, PLACES & ME — Teacher Guide

**Age:** 11–12  
**Level:** A1+ → A2  
**Mode:** one student + one tutor  
**Course:** Spotlight 6, Module 1 companion course

## Method

Each mission follows: **context → notice → understand → practise → retrieve → personalise → communicate**. Closed tasks are self-checking; speaking and writing use visible tutor/self-check prompts rather than fake automated marking.

## Suggested route

1. **Family Files** — family relationships + `have got`
2. **Face Detective** — appearance + descriptive language
3. **Whose Is It?** — possessive adjectives, possessive pronouns, possessive ’s
4. **Identity Check** — personal information + functional questions + greetings
5. **Passport Quest** — countries and nationalities
6. **Where in the World?** — compass directions + location language
7. **Country Lab** — factfiles + UK culture + geography/number-reading extension
8. **The World File** — mixed retrieval + character profile + speaking

## 1:1 interaction

Use the **Tutor Follow-up** strips after major activities. For the first speaking attempt, do not interrupt. Note one successful feature and one target improvement, then repeat if useful.

## Correction priority

- meaning first;
- `have got` form and word order;
- possessive adjective vs possessive pronoun;
- country vs nationality;
- capitalisation of proper nouns;
- full-sentence answers in speaking.

## Reset

**NEW STUDENT** clears answers, progress, attempts, open mission position and generated profile from the browser and returns to the course map.

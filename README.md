# Panoramic A2 — Module 1

Локальная доработка существующего сайта для индивидуальных занятий. Изменения пока не опубликованы.

## Запуск

Статический сайт: запустите любой HTTP-сервер в папке проекта, например `python -m http.server 4173`, и откройте `http://localhost:4173/`.
Node.js используется только для проверок: `npm test`, `npm run build`. Готовая статическая сборка появляется в `dist/`. Зависимости устанавливать не требуется.

## Учебные материалы

Откройте меню → Материалы и импортируйте `panoramic-module1-materials.json`. Пакет предоставляется отдельно от исходного кода: 88 наборов контекста упражнений, оригинальные иллюстрации, 18 справочных страниц и 13 аудиозаписей. Импорт нужен один раз для каждого браузера и адреса сайта. Данные хранятся в IndexedDB; очистка данных браузера удаляет их. Оригинальные PDF и MP3 в публичную сборку не включены.

В Student Mode Module 1 отображаются самостоятельные задания с текстом, иллюстрациями и полями ответа. Полные страницы доступны только в свёрнутом справочнике Teacher Mode. Содержание Modules 2 и 3 в этой доработке не изменено.

## Занятие

Панель занятия: выбор урока и упражнения, назад/далее, одно задание и спокойный вид. Ответы и позиция сохраняются отдельно для каждого локального профиля. Письменные задания автоматически проверяют объём; содержание и язык оценивает преподаватель. Устные задания используют преподавательские отметки.

Teacher Mode показывает ключи отдельно от ответов ученика, компактные рекомендации и заметки. Это режим отображения на одном устройстве, а не защищённая серверная авторизация. Профили и прогресс локальные; синхронизации между компьютерами нет.

## Структура

`js/exercises.js` — компоненты и проверка; `sentence-builder.js` — сборка предложений; `lesson-workspace.js` — навигация; `lesson-content.js` и `materials.js` — локальный контент; `audiolib.js` — аудио; `data-corrections.js` — исправления только Module 1; `css/course.css` — оформление Module 1; `keks.js` — оригинальный помощник Кекс.

После изменения исходных JS/CSS обновляйте версии ссылок в index.html либо используйте сборку: она добавляет хеш содержимого к URL ресурсов.

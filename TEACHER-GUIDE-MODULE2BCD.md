# Spotlight 6 · 2b / 2c / 2d — Teacher guide

Возраст 11–12 лет, уровень A1+ с поддержкой → A2, один ученик + преподаватель. Интерфейс продолжает утверждённую версию 2a: те же цвета, типографика, навигация, понятные русские объяснения, подсказки и повторы.

Откройте главную ссылку сайта и нажмите 2b, 2c или 2d сверху. Прямые входы:

- module2-world.html#b
- module2-world.html#c
- module2-world.html#d

Существующие 2a и Module 1 сохранены. Сброс в любом разделе очищает весь курс, включая новые планы и тексты.

## 2b My place / Move-in Studio

Два занятия по 45–60 минут.

1. Room radar: 6 комнат, контекст и интерактивный план гостиной. Нажатие на предмет открывает слово, IPA и значение. Все объекты доступны и обычными кнопками под рисунком.
2. Object files: 18 слов комнаты + 13 других предметов дома, word cards, Object mystery, самостоятельный ввод и дополнительные серии. Привязка слова к комнате — стратегия запоминания, а не утверждение, что предмет бывает только там.
3. Inventory lab: there is/are, a/an по звуку, some/any для исчисляемого множественного и неисчисляемого, исключение some в просьбах, something/anything, somebody/someone/anybody/anyone, единственное число. Glitch hunt исправляет конкретные формы, не подменяет обучение терминологией.
4. Moving crew: 8 предлогов с понятными схемами и игра расстановки мебели. В плане сначала ставится диван перед окном, затем кресло между камином и дверью, столик перед креслом, лампа справа от столика, ковёр под столиком. Предметы сохраняются между раундами.
5. Move-in conversation: переработанный диалог и вопросы стоят рядом. Проверяются общий смысл, отношения людей и отсылки he / we / it. Phrase hunt ищет реальные выражения из отображаемого диалога.
6. Question studio: where / who / what / which / when / whose; /w/ в we, win, when, why и т. п.; silent w в who/whose. Звук объясняется через положение губ, есть модель преподавателя и необязательный системный голос.
7. Room atelier: собственный план с выбором и перемещением предметов, разговорные опоры, 4–6 предложений, чек-лист и tutor feedback. Открытый текст не оценивается автоматически.
8. Room ready: смешанная проверка и 5 can-do для рефлексии.

Основной маршрут на первой встрече: комнаты → несколько предметов → количества. На второй: расположение → чтение → вопросы → описание. Дополнительные словарные серии не нужно проходить все подряд.

## 2c My neighbourhood / Neighbourhood Club

50–60 минут плюс Extra Practice.

- 12 мест, IPA, значения; 6 товаров из учебника; специализация магазинов; buy / get / borrow; при необходимости bought для дополнительного рассказа.
- Tony’s neighbourhood: предсказание слов, чтение, карта рядом, вопросы с доказательствами и Map detective. Карта спроектирована так, чтобы все предлоги соответствовали её расположению.
- Local radio: новый скрипт для нашей карты; первое слушание — старт, второе — отношения мест. Игра скрывает три названия, затем появляются Core Check и transcript после попытки.
- Delivery day: 12 различных поручений с уточнением специализации. Ученику не нужно угадывать, почему товар нельзя взять в супермаркете: условие просит специализированное место. Aspirin — только единица словарного задания.
- My neighbourhood: собственная карта, 5–7 предложений, вопросы преподавателя, ручной чек-лист и рефлексия.

Скрипт аудирования находится в Tutor Notes. При отсутствии голоса устройства прочитайте его дважды. Оригинальная аудиозапись учебника не имитируется.

## 2d Famous Streets / Street Editors

45–60 минут.

- Три новых учебных текста: Oxford Street, Hollywood Boulevard, Wall Street. Источники официальные; ссылки доступны под текстами.
- Каждый источник и его вопросы показаны рядом; завершение чтения требует ответов по всем трём файлам.
- Посетители David, Stella, Peter и Claire подбирают улицу по интересам. Затем True / False / Not mentioned: только доказательство из текста, без догадок.
- Street code press: St, Rd, Ave, Blvd, Pl, Ln, раскрытие значения и самостоятельный ввод полной формы.
- Мастерская туристического гида: местоположение, места, расположение, занятия, личная рекомендация. Собственный текст — 60–70 английских слов. Образец Maple Street выдуманный, 61 слово.

Сайт считает слова и проверяет заполнение чек-листа, но не выдаёт автоматическую оценку смысла/языка. Кнопка завершения не публикует текст и никуда его не отправляет. Возможен локальный TXT-экспорт.

## Проверка и ограничения

В текущей сборке выполнены:

- проверки синтаксиса всех JavaScript-файлов;
- 972 проверки данных, альтернативных ответов, ошибок, повторов и событий новых модулей;
- проверка 120 закрытых пунктов, включая дополнительные лексические серии;
- формирование 36 видимых представлений новых разделов;
- реальные обработчики действий в тестовом DOM-стенде: matching, ввод, glitch hunt, расстановка, карты, доставки, visitors, codes, звуки, phrase hunt, собственные планы, длина текста, ручные условия завершения и полный reset;
- повторный запуск проверок 2a после добавления навигации и общего reset.

Это Node VM/DOM-стенд и структурная проверка HTML/SVG. Реальная браузерная проверка недоступна в этой среде; визуальное отображение на устройствах, touch и фактическое звучание системного голоса остаются непроверенными. Адаптивные сетки, видимый фокус, альтернативные кнопки к SVG и контрастная палитра заложены в CSS.
